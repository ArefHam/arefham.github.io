# aref.eveai.cloud

Source of [Aref Hammadi's portfolio](https://aref.eveai.cloud). One hand-written HTML file, no build step, served by GitHub Pages.

- `index.html`: the whole page (styles and the small script are inline)
- `img/`: Sila renders and face, social preview image
- `CNAME`: custom domain

Edit `index.html`, push to `main`, and Pages republishes in about a minute.
